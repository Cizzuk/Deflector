# Deflector

With Deflector, you can add buttons to the Dynamic Island and Lock Screen to run any shortcut.
You can long-press the Dynamic Island to quickly run shortcuts.

On supported iPhones in Japan, you can use your preferred voice assistant via shortcuts using the Side Button.
You can create a shortcut that opens the app of the voice assistant or starts voice recognition, allowing you to use various assistants.

To use Deflector, you need to set up an automation in the Shortcuts app. The automation is available within the app.
